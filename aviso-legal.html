Objeto

Esta web informa sobre el servicio de alquiler de autocaravanas de Autocaravanas Ruta 340, sus tarifas, condiciones y disponibilidad, y permite enviar solicitudes de reserva. Las solicitudes enviadas desde la web no constituyen una reserva confirmada hasta que el titular confirma la disponibilidad y se abona la señal.

Condiciones de uso

El acceso a la web es gratuito e implica la aceptación de este aviso legal. El usuario se compromete a usarla de forma lícita, a facilitar datos verdaderos y a no realizar acciones que puedan dañar la web o a terceros.

Precios y disponibilidad

Los precios mostrados incluyen los impuestos aplicables y se calculan de forma orientativa según las temporadas publicadas. El precio definitivo se indicará al confirmar la reserva. El calendario de disponibilidad se actualiza manualmente y puede no reflejar reservas muy recientes.

Las condiciones que se resumen en la web (fianza, seguro, kilometraje, cancelaciones, recargos…) son las del contrato de alquiler que se firma al recoger la autocaravana, que es el documento que rige la relación entre las partes. Si hubiera alguna diferencia, prevalece el contrato.
